মুহাম্মদ তালহা — ব্যক্তিগত পরিচিতিমূলক ওয়েবসাইট

ফাইল:
- index.html : সম্পূর্ণ ওয়েবসাইট (HTML, CSS, JavaScript একই ফাইলে)

মোবাইল থেকে লাইভ করার সহজ উপায় (Netlify Drop):
১. ZIP ফাইলটি Extract/Unzip করুন।
২. Chrome-এ https://app.netlify.com/drop খুলুন।
৩. Netlify-তে লগইন করে Extract করা ফোল্ডারটি আপলোড করুন।
৪. তৈরি হওয়া বিনামূল্যের .netlify.app ঠিকানায় ওয়েবসাইট দেখা যাবে।

গুরুত্বপূর্ণ:
- Facebook, YouTube, WhatsApp ও ইমেইলের লিংকগুলো আপাতত নমুনা। index.html ফাইলে নিজের সঠিক লিংক বসাতে হবে।
- প্রোফাইল ছবির জায়গায় আপাতত “ত” অক্ষরের ডিজাইন রাখা হয়েছে। চাইলে পরে ছবি যোগ করা যাবে।
- নাম/পদবি বা পরিচিতির কোনো তথ্য পরিবর্তন করতে index.html ফাইল সম্পাদনা করুন।
